# AutoNumeric old documentation repository

The official documentation for [AutoNumeric](https://github.com/autoNumeric/autoNumeric/) is no longer stored in this repository, but directly in the [autonumeric.org repository](https://github.com/autoNumeric/autonumeric.org/).

The documentation can be accessed on the official AutoNumeric website [http://autonumeric.org/docs/](http://autonumeric.org/docs), where additional tools can be found.

# Redirections

This repository is archived with empty index.html files that redirects to the new website, in order to keep the previous links created during the last 10 years.
